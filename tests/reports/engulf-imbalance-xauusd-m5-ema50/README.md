# EMA50 check: EngulfImbalanceFlow on XAUUSD M5

## ผลหลัก

Replay สัญญาณผ่าน core ปัจจุบันของ EngulfImbalanceFlow 1.05 โดยใช้ FVG-only และ max gap 5 ได้ 554 สัญญาณ กฎ EMA50 ทั้งสามแบบเลือกสัญญาณชุดเดียวกัน 464 รายการ แต่ผลรวมลดจาก WR 50.36% เป็น 49.78%, gross PF จาก 1.015 เป็น 0.991 และ expectancy จาก +0.0072R เป็น −0.0043R ต่อสัญญาณที่ตัดสินผลได้

กฎที่ทดสอบ:

- Close อยู่เหนือ/ใต้ EMA50 ณ เวลาปิดแท่งสัญญาณ
- EMA50 ปัจจุบันชันขึ้น/ลงเทียบกับแท่งก่อนหน้า
- ต้องผ่านทั้งสองข้อ

ทั้งสามกฎเทียบเท่ากันทางพีชคณิตสำหรับ EMA alpha=2/51: EMA[i]−EMA[i−1] = alpha × (Close[i]−EMA[i−1]) และ Close[i]−EMA[i] = (1−alpha) × (Close[i]−EMA[i−1]) ดังนั้นทั้งความชันและตำแหน่ง Close เทียบกับ EMA[i] จึงบอกเครื่องหมายเดียวกับ Close[i] เทียบ EMA[i−1]. การ replay ตรวจดัชนีที่ผ่านแต่ละข้อจริงและพบว่าตรงกันทุกสัญญาณ

## วิธีและข้อจำกัด

- หน้าต่างสัญญาณ UTC: 2025-09-27 00:00 รวม ถึงก่อน 2026-09-28 00:00. ข้อมูลเริ่ม 2025-09-01 00:00 เพื่อ warm-up EMA และแท่งสุดท้ายที่มีคือ 2026-09-25 20:55 UTC. ไม่มีแท่งหลังเวลานั้น จึงไม่มีข้อมูลช่วงท้ายที่ขาดถึง 2026-09-27 และไม่มีการสังเคราะห์ราคา
- อินพุตคือ Dukascopy M5 UTC ใน ../engulf-imbalance-xauusd-m5/m5_bars.csv; จำนวนแท่งและ SHA-256 อยู่ใน summary.json.
- EMA50 ใช้ alpha=2/51 ตั้ง seed ด้วย Close แรกที่มี และคำนวณผ่านทุกแท่งก่อนสัญญาณ; ใช้เฉพาะ EMA ณ แท่งสัญญาณปิด ไม่ใช้ข้อมูลอนาคต
- FVG ใช้ค่าเริ่มต้น gap ขั้นต่ำ 0, point 0.001, ไม่บังคับทิศแท่งกลาง และไม่รวม displacement. EIFind ปัจจุบันใช้ประวัติที่โหลดทั้งหมดและ maxGap=5; A/B/A+B เป็นคลาสจาก core เอง
- Entry คือราคาเปิดแท่งถัดไป. SL คือ low/high สุดขั้วของแท่งก่อนหน้าและแท่งสัญญาณ เผื่อ 15 จุด (0.015); TP คือ 1R. ตรวจ high/low ตั้งแต่แท่ง entry. หากแท่งเดียวแตะทั้ง TP และ SL ให้นับ BOTH เพราะ OHLC บอกลำดับไม่ได้; ถ้าไม่ชนก่อนจบข้อมูลให้นับ UNRESOLVED
- ไม่จำลอง spread, commission, swap, slippage หรือ execution เมื่อเปิด gap ข้ามระดับ. แต่ละสัญญาณประเมินแยกกันและตำแหน่งอาจซ้อนกัน; DD และ loss streak เป็นลำดับเหตุการณ์ ไม่ใช่ผลพอร์ต
- ไฟล์เดิม tests/reports/engulf-imbalance-xauusd-m5/summary.json ระบุ 1.02 และผล FVG+displacement ซึ่งไม่ตรง source ปัจจุบันและขอบเขต FVG-only นี้. การทดสอบนี้ compile/replay core ปัจจุบันใหม่; ไม่แก้ production indicator และไม่ใช้ผล TP/SL เดิม

## ผลลัพธ์และการทำซ้ำ

- run_ema50_analysis.py: ตรวจข้อมูล, compile/replay core, คำนวณ metrics
- replay_fvg.cpp: runner FVG-only ที่เรียก current EngulfImbalanceCore
- core_fvg_events.csv: สัญญาณ raw จาก core
- filtered_events.csv: EMA, entry/SL/TP, outcomes และสถานะผ่านกฎต่อสัญญาณ
- comparison.csv: breakdown ทุก filter × class × side
- monthly.csv: breakdown รายเดือน
- summary.json: hashes, versions, coverage, assumptions, metrics

รันจากราก repo โดยใช้ Python 3 และ clang++ หรือ g++:

    python3 tests/reports/engulf-imbalance-xauusd-m5-ema50/run_ema50_analysis.py
