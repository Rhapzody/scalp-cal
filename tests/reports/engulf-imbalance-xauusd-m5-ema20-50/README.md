## ผลรวม

Replay FVG-only ด้วย EngulfImbalanceFlow 1.05 core ปัจจุบันและ maxGap=5 ได้ 554 สัญญาณ; ได้ตรวจยืนยัน data/source hashes และ hash ของ raw core events ตรงกับงาน EMA50 ก่อนหน้าแบบ byte-for-byte. ตัวกรอง EMA20/50 ที่แท่งสัญญาณเลือก 328 สัญญาณ; ตัวกรอง robustness ที่ใช้ความสัมพันธ์ EMA ณ แท่งปิดก่อนหน้าเลือก 310 สัญญาณ

EMA20/50 ปัจจุบันลด WR ราว 0.06 จุดเปอร์เซ็นต์จาก baseline (50.30% เทียบ 50.36%). รุ่นใช้แท่งก่อนหน้าเพิ่มราว 0.61 จุดเปอร์เซ็นต์ แต่ช่วง Wilson กว้างและทับกับ baseline มาก จึงยังไม่มีหลักฐานว่าได้เปรียบจริงหรือจะคงอยู่เมื่อเปลี่ยนช่วงข้อมูล

## วิธีและขอบเขต

- หน้าต่างสัญญาณ UTC คือ 2025-09-27 00:00 รวม ถึงก่อน 2026-09-28 00:00. อินพุตมี 75,505 แท่งตั้งแต่ 2025-09-01 00:00 ถึง 2026-09-25 20:55 UTC; ไม่มีแท่งหลังจากนั้น จึงขาดช่วงท้ายถึง 2026-09-27. ไม่มีการสร้างราคาแทนข้อมูลที่ไม่มี
- ใช้ไฟล์เดิม ../engulf-imbalance-xauusd-m5/m5_bars.csv. SHA-256 คือ 16323f99e604f4df40895db0b6a4d6c4e61d809f3e1b41fc9028f84a8d448215; source และผล replay ที่ตรวจเทียบอยู่ใน summary.json.
- EMA20/EMA50 ใช้ alpha 2/(N+1), seed ด้วย Close แรกของชุดข้อมูลเดียวกัน และคำนวณผ่าน warm-up ทั้งหมด. EMA ใช้เฉพาะแท่งปิดแล้ว. กฎปัจจุบันเลือก BUY เมื่อ EMA20>EMA50 และ SELL เมื่อ EMA20<EMA50; ค่าเท่ากันไม่ผ่าน. Robustness ใช้ความสัมพันธ์ EMA ของแท่งที่ปิดก่อนแท่งสัญญาณหนึ่งแท่ง (i−1); ไม่ได้ลองปรับ period
- ใช้ current EIFind, FVG-only, maxGap=5, point 0.001, minimum FVG gap 0, ไม่บังคับทิศทางแท่งกลาง และตัด displacement ออก; แยกผล A/B/A+B
- Entry คือราคาเปิดแท่งถัดไป; SL อยู่เลย high/low สุดขั้วของแท่งก่อนหน้าและแท่งสัญญาณ 15 จุด (0.015); TP=1R. ตรวจ OHLC ตั้งแต่แท่ง entry. หากแท่งเดียวแตะทั้งสองระดับนับ BOTH และตัดจาก WR/PF/expectancy/DD; หากไม่ชนก่อนจบข้อมูลนับ UNRESOLVED
- PF และ expectancy เป็น gross, ไม่คิด spread, commission, swap หรือ slippage. สัญญาณตรวจแยกกันและอาจซ้อนกัน; sequential DD / loss streak ไม่ใช่ผลพอร์ต
- legacy summary.json ในโฟลเดอร์ M5 เดิมระบุ 1.02 และ FVG+displacement. งานนี้สร้าง replay ใหม่จาก current 1.05 core; ไม่มีการแก้ production indicator

## ไฟล์และการทำซ้ำ

- run_ema20_50_analysis.py และ replay_fvg.cpp: build/replay current core และคำนวณผล
- core_fvg_events.csv: raw events; SHA-256 ที่ตรวจเทียบกับ replay ก่อนหน้าคือ 71fdcc2595881920d2b4a1da63021b9ddc08720b6cf35d0d0782485e2c2c36ab
- filtered_events.csv: EMA20/50, สถานะผ่านแต่ละกฎ, entry/SL/TP และผลต่อสัญญาณ
- comparison.csv: ทุก filter × class × side พร้อม Wilson CI, PF, expectancy, DD, loss streak
- monthly.csv: breakdown รายเดือนของ metrics ชุดเดียวกัน
- summary.json: hashes, exact coverage, validation, settings และผลรวม
