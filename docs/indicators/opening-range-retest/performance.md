# Opening Range Retest — ผลตลาด

ยังไม่มี backtest หรือ forward test ของ symbol/broker ใดในชุดนี้ จึงไม่มีค่า win rate ที่รับรองได้

ให้บันทึกจำนวน trade, win rate, average win/loss สุทธิ, realized RR, expectancy, profit factor, maximum drawdown, spread, commission และผลแยก Buy/Sell ในช่วง in-sample และ out-of-sample แยกกัน
