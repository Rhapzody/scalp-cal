# MACD Swing Count — MT5 Indicator 1.20

Indicator ใหม่ในชุด MT5 Trading Tools พัฒนาจากแนวคิดของ `MACD_CROSS_SwingCount` 3.1: ใช้ MACD/Signal แบ่งราคาเป็นขาขึ้นและขาลง หาจุด Swing High/Low แล้วใส่เลขย้อนหลังบนกราฟ เพิ่มการจำแนก HH/HL/LH/LL, เครื่องหมายบนแท่งยืนยัน และ output สำหรับ EA ที่แยกเวลาเกิดยอด/ก้นออกจากเวลายืนยัน

อ่านรายการแก้ไขและความแตกต่างจากต้นฉบับใน [CHANGELOG.md](CHANGELOG.md) และผลทดสอบใน [testing.md](testing.md)

เวอร์ชัน 1.10 เพิ่ม **Histogram color mode** สำหรับตรวจโครงสร้างย่อยภายในขา MACD เดิม เลือกได้จาก **Inputs → Swing detection mode → InpSwingMode → Histogram color (minor swings)** ค่าเริ่มต้นยังเป็น MACD / Signal cross

เวอร์ชัน 1.20 เพิ่ม **เส้นแนวรับ/แนวต้านจาก swing** เปิด–ปิดและกำหนดจำนวนแยกจากเลขนับ เลือกวางที่ wick หรือขอบเนื้อเทียนของแท่ง swing ได้ ใช้ได้ทั้งสองโหมด

## ติดตั้ง

1. แตก `MACDSwingCount-1.20.zip`
2. MT5 → **File → Open Data Folder**
3. คัดลอกโฟลเดอร์ `MQL5/Indicators/MACDSwingCount` ในชุดติดตั้ง ไปยัง `MQL5/Indicators` ของ Data Folder
4. Navigator → Indicators → คลิกขวา **Refresh** แล้วลาก **MACDSwingCount** ลงกราฟ
5. เปลี่ยนค่าที่ **Ctrl+I → MACDSwingCount → Properties → Inputs**

ใช้ไฟล์ `.ex5` ได้ทันที ถ้าแก้ source เปิด `MACDSwingCount.mq5` ใน MetaEditor แล้วกด F7 โดยเก็บ `SwingCore.mqh` ไว้ข้างกัน ใช้ร่วมกับ EA และ indicator อื่นได้ ไม่ต้องเปิด Algo Trading

## การคำนวณ

ใช้ symbol/timeframe ของกราฟ และราคาปิดของแท่งที่ปิดแล้วเท่านั้น:

```text
Fast      = EMA(Close, InpFastEMA)
Slow      = EMA(Close, InpSlowEMA)
MACD      = Fast − Slow
Signal    = EMA(MACD, InpSignalEMA)
Histogram = MACD − Signal
```

EMA เริ่มจาก source แรกที่ใช้ได้ แล้วคำนวณ `alpha × source + (1 − alpha) × previous`, โดย `alpha = 2 / (length + 1)` Signal เริ่มที่ 0 เพราะ MACD แรกเท่ากับ 0 วิธี seed และ recurrence สอดคล้องกับโหมด EMA/EMA, Close ของ TVStyleMACD ในโปรเจคนี้ แต่เป็น implementation ภายใน `SwingCore.mqh` ของชุดนี้ เพื่อให้ติดตั้งเป็นอิสระได้

ไม่มี iMACD handle ที่ไม่ได้ใช้ ไม่มีการเอาค่าเฉลี่ยจากแท่งถัดไปมาใส่ย้อนในช่วงต้น และไม่ใช้แท่งสดในการ seed แม้ period ยาวกว่าประวัติที่โหลด ค่าใน buffer 8–11 แสดงตั้งแต่แท่งแรกเพื่อการตรวจสอบ แม้ยังอยู่ใน warmup จึงยังไม่ถือว่าเกิด swing

`InpWarmupBars=0` ใช้ `max(FastEMA, SlowEMA) + SignalEMA − 1` แท่ง ค่าเริ่มต้นคือ **34 แท่ง**; เฉพาะโหมด MACD cross ที่เลือกตัวกรอง ATR จะรออย่างน้อย ATR length ด้วย หลังครบ warmup เริ่มขาแรกเมื่อมีทิศที่ผ่านกติกาของโหมดนั้น โดยเริ่มเก็บ extreme จากแท่งนั้น ไม่สร้าง swing จากข้อมูลที่ข้ามไป ไม่ย้อนนับ extreme ช่วง warmup

การ warmup ลดผลเริ่มต้น แต่ไม่ได้ทำให้ EMA ไม่ขึ้นกับจุดเริ่มประวัติ หากต้องการเพิ่มจำนวนแท่งที่รอให้ตั้ง `InpWarmupBars` เอง ถ้า period ยาวกว่าประวัติที่มีจะยังไม่มี swing ตามค่า warmup อัตโนมัติ

ถ้า Fast เท่ากับ Slow จะได้ MACD/Histogram เป็นศูนย์ หรือถ้า Signal length = 1 จะได้ Signal เท่ากับ MACD จึงไม่มี swing จากการข้ามฝั่ง ทั้งสองกรณีเป็นค่าที่สูตรรองรับแต่ไม่ได้ให้สัญญาณ

## โหมด Histogram color — โครงสร้างย่อย

ตั้ง `InpSwingMode=MS_HISTOGRAM_COLOR` ใช้กติกา 4 สีเดียวกับ TVStyleMACD โดยเปรียบเทียบ **ค่า Histogram ที่มีเครื่องหมายบวก/ลบ** กับแท่งปิดก่อนหน้า ไม่ใช่เปรียบเทียบค่าสัมบูรณ์หรืออ่านสีจาก object บนกราฟ

| สีตามค่าเริ่มต้นของ TVStyleMACD | เงื่อนไข | ทิศของขา |
|---|---|---|
| เขียวเข้ม | Histogram ≥ 0 และค่ามากกว่าแท่งก่อน | ขึ้น |
| เขียวอ่อน | Histogram ≥ 0 และค่าไม่มากกว่าแท่งก่อน | ลง |
| แดงอ่อน | Histogram < 0 และค่ามากกว่าแท่งก่อน (ติดลบน้อยลง) | ขึ้น |
| แดงเข้ม | Histogram < 0 และค่าไม่มากกว่าแท่งก่อน | ลง |

- แดงเข้ม → แดงอ่อน หรือเขียวอ่อน → เขียวเข้ม: เปลี่ยนขึ้น ยืนยัน Low ของขาลงเดิม
- แดงอ่อน → แดงเข้ม หรือเขียวเข้ม → เขียวอ่อน: เปลี่ยนลง ยืนยัน High ของขาขึ้นเดิม
- เขียว → แดง: เป็นทิศลง แม้กระโดดจากเขียวเข้มไปแดงโดยไม่มีเขียวอ่อนคั่น
- แดง → เขียว: เป็นทิศขึ้น แม้กระโดดจากแดงเข้มไปเขียวโดยไม่มีแดงอ่อนคั่น
- หากอยู่ในทิศนั้นอยู่แล้วจะเก็บ extreme ต่อ ไม่สร้างจุดซ้ำ เช่น **เขียวเข้ม → เขียวอ่อน → แดง** ยืนยัน High ตอนเปลี่ยนเป็นเขียวอ่อน จากนั้นสีแดงต่อขาลงเดิม
- **เขียวเข้ม → เขียวเข้ม → แดง** ยืนยัน High ตอนแท่งแดงปิด; ฝั่งแดงใช้กติกากลับด้าน
- สีเดิมซ้ำยังเป็นขาเดิม จุด High/Low ใช้ราคาบนกราฟ ไม่ใช่ยอด/ก้นของ Histogram

ตัวอย่าง Histogram `−0.10 → −0.20 → −0.10 → −0.20`: แท่งที่สองเป็นแดงเข้มและเริ่มขาลง แท่งที่สามเป็นแดงอ่อนจึงยืนยัน Swing Low และแท่งที่สี่เป็นแดงเข้มจึงยืนยัน Swing High แม้ Histogram ยังอยู่ใต้ศูนย์ตลอด

เมื่อค่า Histogram เท่ากับแท่งก่อนและไม่ใช่ศูนย์ จะใช้สีฝั่งไม่เพิ่มตาม TVStyleMACD: เขียวอ่อน/แดงเข้ม จึงสามารถเปลี่ยนลงได้แม้ค่าจะเท่ากัน ถ้าศูนย์ต่อเนื่องสองแท่งจะคงทิศเดิมและไม่สร้างทิศจาก series ศูนย์ล้วน แท่งแรกที่ยังไม่มีค่า Histogram ก่อนหน้าให้เทียบยังไม่สร้างขา

**ตัวกรอง `InpMinHistogram`, `InpThresholdMode`, `InpATRLength` ไม่ใช้กรอง swing ในโหมดสี** เพื่อรับการเปลี่ยนสีตามกติกาโดยตรง Buffer 11 เป็น 0 บนแท่งปิดที่ข้อมูลใช้ได้ และ ATR length ไม่เพิ่ม warmup ในโหมดนี้ การเปลี่ยนสีแสดงผลของ TVStyleMACD เองไม่เปลี่ยนกติกาตัวเลขนี้

ใช้ทั้งสองโหมดพร้อมกันได้โดยแนบ indicator สอง instance แล้วเลือกโหมดคนละแบบ เลข, HH/HL/LH/LL และ buffers ของแต่ละ instance นับตาม swing ของโหมดตัวเอง ไม่มีการรวมลำดับโครงสร้างใหญ่/ย่อยเป็นชุดเดียว ชื่อ indicator และ popup ระบุ Cross/Histogram เพื่อแยกกัน

## โหมด MACD cross — กติกาเดิมและตัวกรอง

ตั้ง `InpSwingMode=MS_MACD_CROSS` (ค่าเริ่มต้น) พฤติกรรมเดิมจากเวอร์ชัน 1.00:

- ขาขึ้น: เก็บ High สูงสุดจน Histogram อยู่ฝั่งลบและระยะถึง threshold → ยืนยัน Swing High แล้วเริ่มขาลง
- ขาลง: เก็บ Low ต่ำสุดจน Histogram อยู่ฝั่งบวกและระยะถึง threshold → ยืนยัน Swing Low แล้วเริ่มขาขึ้น
- ระหว่าง Histogram อยู่ใกล้ศูนย์หรือยังไม่ถึง threshold ให้คงขาเดิมและเก็บ extreme ต่อ รวมถึงช่วงที่ข้ามศูนย์แล้วแต่ยังไม่ผ่านเกณฑ์
- `threshold=0` ใช้ทิศบวก/ลบอย่างเคร่งครัด; Histogram เท่ากับ 0 ไม่เปลี่ยนขา
- ระยะเท่ากับ threshold ถือว่าถึงเกณฑ์เมื่อ Histogram มีเครื่องหมายบวก/ลบ
- แท่งยืนยันรวมอยู่ในการหายอด/ก้นของขาเก่า และใช้เป็นแท่งเริ่มขาใหม่ด้วย
- High/Low เท่ากันเลือกแท่งล่าสุด ทั้งสองจุดที่อยู่คนละขาอาจอยู่บนแท่งเดียวกันได้

ตัวอย่าง `threshold=0.05`, ขาเดิมขึ้น และ Histogram เป็น `+0.10 → −0.01 → −0.10`: แท่ง `−0.01` ยังนับอยู่ขาขึ้น เมื่อถึง `−0.10` จึงยืนยัน High โดยไม่ต้องรอ cross ใหม่ จุดยอดจะเป็น High สูงสุดตั้งแต่เริ่มขาจนถึงแท่งยืนยัน ไม่ใช่หยุดเก็บที่แท่ง cross แรก

| Threshold mode | การแปลงเป็นระยะ MACD |
|---|---|
| `MS_PRICE` | `InpMinHistogram` หน่วยราคาโดยตรง |
| `MS_POINTS` | `InpMinHistogram × SYMBOL_POINT` |
| `MS_ATR` | `InpMinHistogram × ATR ของแท่งปิดที่กำลังตรวจ` |

ATR ใช้ True Range และ Wilder smoothing: `previousATR + (TR − previousATR) / length` เริ่มจาก TR แรก สูตร seed นี้ระบุชัดเจนและไม่ได้อ้างว่าตรงกับ iATR ของทุกแพลตฟอร์มในช่วงต้น เมื่อใช้ ATR เกณฑ์จะเปลี่ยนตามแท่ง จึงอาจผ่านเกณฑ์ได้จากระยะ Histogram เพิ่มขึ้นหรือ ATR ลดลง

## อ่านสิ่งที่เห็นบนกราฟ

- **เลข 1 คือ swing ที่ยืนยันล่าสุด** จากนั้น 2, 3, … ย้อนตามลำดับการยืนยัน รวม High และ Low ไม่ใช่ Elliott Wave
- เมื่อมี swing ใหม่ เลขเก่าจะเลื่อน ค่าเริ่มต้นแสดงเลขพร้อมชนิดโครงสร้าง เช่น `1 HH`
- `H` / `L`: High/Low แรกที่ยังไม่มีจุดชนิดเดียวกันก่อนหน้าให้เทียบ
- `HH` / `LH`: High สูงกว่า/ต่ำกว่า High ที่ยืนยันก่อนหน้า; `EH` คือเท่ากัน
- `HL` / `LL`: Low สูงกว่า/ต่ำกว่า Low ที่ยืนยันก่อนหน้า; `EL` คือเท่ากัน
- เปรียบเทียบระดับราคาโดยตรงกับ swing ชนิดเดียวกันล่าสุด ไม่มีระยะ tolerance เพิ่มเติม
- สี Tomato คือ High, DeepSkyBlue คือ Low ปรับได้
- ลูกศรลงเหนือแท่ง = **ยืนยัน High**; ลูกศรขึ้นใต้แท่ง = **ยืนยัน Low** เป็น marker ยืนยันโครงสร้าง ไม่ใช่ระบบส่งคำสั่ง Sell/Buy
- เปิด `InpShowLines` เพื่อเชื่อมจุดที่ยืนยันและอยู่ในจำนวนที่แสดง เส้นหยุดที่ swing ล่าสุด ไม่มีเส้นของจุดกำลังก่อตัว
- Tooltip ของเลขระบุราคา เวลาแท่งยอด/ก้น และเวลาเปิดของแท่งยืนยัน

**ตำแหน่งยอด/ก้น กับเวลาที่รู้ว่าเป็น swing ไม่ใช่เวลาเดียวกัน:** หากยอดอยู่แท่ง 13 และยืนยันเมื่อแท่ง 16 ปิด เลขจะวางที่แท่ง 13 แต่ลูกศรยืนยันอยู่แท่ง 16 และเพิ่งปรากฏเมื่อได้ tick แรกของแท่งถัดไป ไม่สามารถใช้จุดนั้นเป็นสัญญาณที่รู้แล้วตั้งแต่แท่ง 13

## Inputs

กลุ่ม **Swing support / resistance rays** เป็นเส้นระดับราคาใหม่ ส่วน `InpShowLines` เป็นเส้นเชื่อม swing เดิม ทั้งสองอย่างเปิด–ปิดแยกกัน

| Input | ค่าเริ่มต้น | ขอบเขต/ความหมาย |
|---|---:|---|
| `InpFastEMA` | 12 | 1–100000 |
| `InpSlowEMA` | 26 | 1–100000; ยอมให้ Fast ≥ Slow แต่พฤติกรรม MACD จะเปลี่ยน |
| `InpSignalEMA` | 9 | 1–100000; ใช้ EMA จริงตามชื่อ |
| `InpWarmupBars` | 0 | 0 = อัตโนมัติ, 1–1000000 = กำหนดเอง |
| `InpThresholdMode` | MS_PRICE | ราคา / points / ATR |
| `InpMinHistogram` | 0.0 | ค่าจำกัดระยะ ≥ 0 และต้องเป็นตัวเลขที่ใช้ได้ |
| `InpATRLength` | 14 | 1–100000; มีผลต่อ threshold เฉพาะโหมด ATR |
| `InpVisibleSwings` | 10 | 0–1000; จำกัดเฉพาะเลขและเส้นเชื่อม ไม่จำกัดเส้น S/R หรือประวัติใน buffers |
| `InpLabelMode` | MS_NUMBER_STRUCTURE | เลข / โครงสร้าง / เลขพร้อมโครงสร้าง |
| `InpFontSize` | 10 | 6–72 |
| `InpOffsetPoints` | 80 | ระยะเลขจาก wick หน่วย points, ≥ 0 |
| `InpHighColor` | Tomato | สีเลข High และ marker ยืนยัน High |
| `InpLowColor` | DeepSkyBlue | สีเลข Low และ marker ยืนยัน Low |
| `InpShowLines` | false | เส้นเชื่อม swing ที่มองเห็น |
| `InpLineColor` | Silver | สีเส้นเชื่อม |
| `InpShowConfirmation` | true | แสดง marker ที่แท่งยืนยันตลอดประวัติ |
| `InpArrowWidth` | 1 | 1–5 |
| `InpArrowGapPixels` | 12 | ระยะ marker จาก wick หน่วย pixel, 0–1000 |
| `InpPopupAlert` | false | Popup เมื่อมี swing ใหม่ยืนยัน |
| `InpDebug` | false | Log เมื่อ swing เปลี่ยนหรือคำนวณประวัติใหม่ |
| `InpSwingMode` | MS_MACD_CROSS | MACD / Signal cross หรือ MS_HISTOGRAM_COLOR สำหรับโครงสร้างย่อย |
| `InpShowSR` | true | เปิด–ปิดเส้นแนวรับ/แนวต้าน |
| `InpSRCount` | 10 | 0–1000; จำนวน swing ล่าสุดที่วาดเส้น รวม High และ Low ไม่ใช่จำนวนต่อฝั่ง |
| `InpSRAnchor` | MS_SR_WICK | MS_SR_WICK = ปลาย wick, MS_SR_BODY = ขอบเนื้อเทียนของแท่ง swing |
| `InpResistanceColor` | Tomato | สีเส้นจาก Swing High |
| `InpSupportColor` | DeepSkyBlue | สีเส้นจาก Swing Low |
| `InpSRWidth` | 1 | ความหนาเส้น S/R 1–5; เส้นทึบ |

ถ้าต้องการหน้าตาใกล้ต้นฉบับ ตั้ง `InpLabelMode=MS_NUMBER`, `InpShowConfirmation=false`, `InpShowLines=false`, `InpShowSR=false` แต่ตำแหน่ง swing ไม่รับประกันตรงต้นฉบับ เพราะแก้สูตร seed, warmup และตัวกรองแล้ว `InpVisibleSwings=0` ซ่อนเลขและเส้นเชื่อม; ถ้าต้องการซ่อนภาพทั้งหมดให้ปิด marker และ S/R เพิ่มด้วย

## เส้นแนวรับ / แนวต้านจาก swing

เส้นเป็นแนวนอนเริ่มจากแท่งยอด/ก้น แล้วทอดยาวไปทางขวา เกิดขึ้นเมื่อ swing **ยืนยันแล้วเท่านั้น** หากยอดอยู่แท่ง 13 แต่เพิ่งยืนยันเมื่อแท่ง 16 ปิด เส้นจะเริ่มวาดที่แท่ง 13 หลังยืนยัน ไม่ได้เป็นระดับที่รู้ล่วงหน้าตอนแท่ง 13

| จุด swing | Wick | Body |
|---|---|---|
| Swing High → แนวต้าน | High ของแท่ง swing | `max(Open, Close)` ของแท่ง swing |
| Swing Low → แนวรับ | Low ของแท่ง swing | `min(Open, Close)` ของแท่ง swing |

ใช้ **แท่งที่เป็นจุด swing จริง** ไม่ใช่แท่งที่มายืนยันภายหลัง และไม่ใช่แท่งที่มีขอบเนื้อเทียนสูงสุด/ต่ำสุดในทั้งขา หาก wick เท่ากันหลายแท่ง ระบบเลือกแท่งล่าสุดตามกติกาเดิมและใช้ body ของแท่งล่าสุดนั้น Doji ใช้ราคา Open = Close เป็นขอบ body ทั้งสองฝั่ง

ตัวอย่างแท่ง Swing High มี Open 110, Close 100, High 130: เลือก Wick ได้เส้นที่ 130; เลือก Body ได้เส้นที่ 110 โดยเลข swing และ buffer ราคายอดยังอยู่ตาม High 130 เหมือนเดิม

- เปิด/ปิดด้วย `InpShowSR`; `InpSRCount=0` ก็ซ่อนได้
- `InpSRCount=10` ใช้ swing ที่ยืนยันล่าสุดรวม 10 จุด เช่น High 5 + Low 5; ถ้ามีน้อยกว่านั้นจะแสดงเท่าที่มี
- จำนวนเส้นแยกจากเลข เช่น เลข 5 จุด แต่เส้น S/R 20 จุดได้ หรือปิดเลขแล้วยังแสดงเส้นได้
- หนึ่ง swing ต่อหนึ่งเส้น ระดับราคาที่ซ้ำกันอาจทับกันบนกราฟ ไม่มีการรวมเส้นตามราคา
- เมื่อมี swing ใหม่จะตัดเส้นเก่าที่พ้นจำนวนที่ตั้งไว้ ไม่ลบเส้นอัตโนมัติเมื่อราคาทะลุ และไม่สลับสีแนวรับ/ต้านตามการทะลุ
- Body/Wick เปลี่ยนเฉพาะระดับเส้น S/R ไม่เปลี่ยนการหา swing, HH/HL/LH/LL, เลข, marker, เส้นเชื่อม หรือ buffers 0–11
- สีแนวรับ/ต้านและความหนาตั้งแยกได้ Tooltip ระบุว่าเป็นระดับ wick หรือ body
- แต่ละ instance จัดการเส้นของตนเอง ใช้ Cross กับ Histogram color คนละ instance เพื่อดูระดับจากโครงสร้างใหญ่และย่อยได้

ใช้ object แบบ [OBJ_TREND ของ MT5](https://www.mql5.com/en/docs/constants/objectconstants/enum_object/obj_trend) โดยกำหนดสองจุดให้มีราคาเดียวกัน เปิดการต่อเส้นทางขวาและปิดทางซ้าย เส้นเหล่านี้เป็น chart objects ไม่มี output buffer S/R เพิ่มในเวอร์ชันนี้

## Alerts และการโหลดประวัติ

Popup เริ่มต้นปิด เปิดได้จาก Inputs แจ้งครั้งเดียวสำหรับ swing ที่ยืนยันบนแท่งปิดล่าสุด ไม่มีแจ้งย้อนหลังตอน attach, เปลี่ยน Inputs/timeframe หรือ rebuild ประวัติ เมื่อข้อมูลเข้ามาหลายแท่งพร้อมกันจะพิจารณาแจ้งเฉพาะ event บนแท่งปิดล่าสุด ไม่เล่น alert เก่าทีละรายการ Debug สรุป event ล่าสุดและระบุการ rebuild ไม่พิมพ์ซ้ำทุก tick

ทำงานกับแท่งปิดเท่านั้นและไม่เปลี่ยน event ที่ยืนยันแล้วจาก tick ของแท่งสด เมื่อ OHLC และขอบเขตประวัติคงเดิม การโหลดใหม่กับการเดินข้อมูลทีละแท่งให้ผลตรงกันตามชุดทดสอบ อย่างไรก็ตามการเพิ่มข้อมูลเก่าทางซ้าย, broker แก้ราคา, เปลี่ยน Inputs/timeframe หรือเลื่อนขอบประวัติเมื่อจำกัดจำนวนแท่ง ทำให้คำนวณใหม่และ swing อาจเปลี่ยนได้ เลขที่เลื่อนเมื่อมี swing ใหม่เป็นพฤติกรรมการแสดงผลตามปกติ

## Output สำหรับ EA / iCustom

ใช้ path `MACDSwingCount\\MACDSwingCount` กับ `iCustom` และอ่านด้วย `CopyBuffer` **ทุก buffer ใช้ `EMPTY_VALUE` เมื่อไม่มีค่า ไม่ใช่ 0 แบบต้นฉบับ** แท่งสด shift 0 ว่างทั้งหมด ค่าที่อ่านเป็นราคาจริง ไม่รวมระยะ pixel/points สำหรับการวาด

| Buffer | ค่า | วางที่แท่งใด |
|---:|---|---|
| 0 | ราคา Swing High | แท่งยอด; ถูกเติมย้อนหลังเมื่อยืนยัน |
| 1 | ราคา Swing Low | แท่งก้น; ถูกเติมย้อนหลังเมื่อยืนยัน |
| 2 | Event type: +1 High, −1 Low | แท่งยืนยัน |
| 3 | ราคายอด/ก้นของ event | แท่งยืนยัน |
| 4 | เวลาเปิดแท่งยอด/ก้น เป็น Unix seconds ใน double | แท่งยืนยัน |
| 5 | Structure code ตามตารางด้านล่าง | แท่งยืนยัน |
| 6 | High ของแท่งยืนยัน High | แท่งยืนยัน; เป็นตำแหน่ง marker ไม่จำเป็นต้องเป็นราคายอด |
| 7 | Low ของแท่งยืนยัน Low | แท่งยืนยัน; เป็นตำแหน่ง marker ไม่จำเป็นต้องเป็นราคาก้น |
| 8 | MACD | ทุกแท่งปิด รวม warmup |
| 9 | Signal EMA | ทุกแท่งปิด รวม warmup |
| 10 | Histogram | ทุกแท่งปิด รวม warmup |
| 11 | Threshold ที่แปลงเป็นหน่วยราคาแล้ว; โหมดสี = 0 | ทุกแท่งปิด รวม warmup |

| Code | ความหมาย | Code | ความหมาย |
|---:|---|---:|---|
| 1 | HH | −1 | HL |
| 2 | LH | −2 | LL |
| 3 | EH | −3 | EL |
| 4 | High แรก | −4 | Low แรก |

EA ที่ตรวจทุกแท่งใหม่ให้เริ่มจาก buffer 2 ที่ shift 1 แล้วอ่าน buffer 3–5 ของ shift เดียวกัน ต้องตรวจ `CopyBuffer` ว่าสำเร็จและค่าไม่ใช่ `EMPTY_VALUE` ถ้าหลุดการเชื่อมต่อหรือไม่ได้ตรวจหลายแท่ง ให้ไล่ events ตั้งแต่เวลาแท่งที่ประมวลผลล่าสุดเพื่อไม่ข้าม event และบันทึกเวลาแท่งยืนยันเพื่อป้องกันทำซ้ำ

Input ใหม่ `InpSwingMode` ต่อท้าย Inputs เดิม เพื่อคงลำดับ positional arguments ของ `iCustom` จาก 1.00 การเรียกเดิมที่ไม่ส่ง mode จะใช้ Cross ตามเดิม หมายเลข buffers 0–11 และความหมาย event/classification ไม่เปลี่ยน

Inputs กลุ่ม S/R ของ 1.20 ต่อท้าย `InpSwingMode` อีกครั้ง เพื่อคงลำดับ arguments ของ 1.10; `InpShowSR` เริ่มต้นเปิด หากใช้ iCustom เพื่ออ่านค่าอย่างเดียวสามารถส่งค่า false ในตำแหน่งนี้เพื่อปิดการวาดเส้นได้

เวลาใน buffer 4 และ tooltip เป็น **เวลาเปิดแท่ง** ตาม series ของ MT5 เวลาที่สามารถใช้ event ได้จริงคือหลังแท่งยืนยันปิด/มี tick แรกของแท่งใหม่ ไม่ใช่เวลาเปิดแท่งยืนยัน และไม่ใช่เวลาเปิดแท่งยอด/ก้น ห้ามนำ buffers 0/1 ไปใช้เป็นสัญญาณที่ทราบล่วงหน้าใน backtest

## ขอบเขต

ไม่มีการเปิด/ปิดออเดอร์, คำนวณ SL/TP/RR, Telegram, MTF, divergence, provisional swing หรือการกรองด้วย PAReversal ในเวอร์ชันนี้ ไม่มี dependency กับ EA `MACD_CROSS_SwingAlert` และยังไม่รับรองความตรงของ swing กับ EA นั้นหรือ TradingView จาก feed จริง
