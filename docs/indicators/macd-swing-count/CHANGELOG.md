# MACD Swing Count — รายการเปลี่ยนแปลง

## 1.20 — 2026-09-12

- เพิ่มเส้นแนวรับ/แนวต้านแนวนอนจาก swing ที่ยืนยันแล้ว ทอดจากแท่ง swing ไปทางขวา ใช้ได้กับทั้ง Cross และ Histogram color
- เพิ่ม `InpShowSR` เปิด–ปิด (ค่าเริ่มต้น true), `InpSRCount` จำนวนเส้นล่าสุดรวม High/Low (ค่าเริ่มต้น 10) แยกจากจำนวนเลขและเส้นเชื่อมเดิม
- เพิ่ม `InpSRAnchor` เลือก Wick หรือ Body: High ใช้ขอบบน body, Low ใช้ขอบล่าง body ของแท่ง swing จริง
- เก็บราคา body พร้อม extreme ใน core และ event รวมถึงกรณี wick เท่ากันที่เลือกแท่งล่าสุด ป้องกันการหยิบ body จากแท่งยืนยันหรือแท่งอื่นในขา
- เพิ่มสีแนวรับ/แนวต้านและความหนาเส้นแยก พร้อม tooltip ระบุชนิดระดับ
- จำกัดเส้นตามจำนวนที่ตั้งไว้และลบเฉพาะเส้นของ instance นั้น ไม่กระทบเลข, เส้นเชื่อม หรือ instance อื่น
- การวาด S/R ไม่เปลี่ยนกติกาตรวจ swing, เลขโครงสร้าง, marker หรือ buffers 0–11; Inputs ใหม่ต่อท้ายเพื่อคงลำดับ iCustom เดิม
- เส้นที่ราคาซ้ำกันยังเป็นคนละ swing และอาจทับกัน ไม่มีระบบลบเมื่อราคาทะลุ/กลับสีแนวรับต้านในเวอร์ชันนี้
- เพิ่มการทดสอบ body ของ pivot ย้อนหลังในทั้งสองโหมด, doji, wick เท่ากัน และ renderer จริงผ่าน MT5 object API จำลอง (ระดับราคา, ray ขวา, สี/ความหนา, จำนวน, เปิดปิด, การแยก instance)
- ผ่าน **42,454 checks รวม**: core/integration 42,436 และ S/R renderer 18 checks

## 1.10 — 2026-09-12

- เพิ่ม `InpSwingMode` เลือก `MS_MACD_CROSS` (ค่าเริ่มต้นเดิม) หรือ `MS_HISTOGRAM_COLOR` เพื่อหา swing ย่อย
- โหมดสีใช้ทิศการเพิ่ม/ไม่เพิ่มของ Histogram ตาม 4 สีของ TVStyleMACD: แดงเข้ม → แดงอ่อนเป็นขึ้น, แดงอ่อน → แดงเข้มเป็นลง และฝั่งเขียวใช้เขียวอ่อน → เขียวเข้มเป็นขึ้น/กลับกันเป็นลง
- รองรับเขียวเข้ม → เขียวเข้ม → แดงเป็นลง และเขียวเข้ม → เขียวอ่อน → แดงเป็นขาลงต่อเนื่อง ไม่สร้าง Swing High ซ้ำตอนข้ามศูนย์ ถ้าเปลี่ยนลงจากสีอ่อนไปแล้ว ฝั่งแดงกลับกติกาเดียวกัน
- ค่าที่เท่ากันและไม่ใช่ศูนย์ใช้สีไม่เพิ่ม (เขียวอ่อน/แดงเข้ม) ให้สอดคล้อง TVStyleMACD; ศูนย์ต่อเนื่องไม่สร้างขาเทียม
- โหมดสีไม่ใช้ตัวกรองระยะ cross และไม่รอ ATR warmup ที่ไม่เกี่ยวข้อง Buffer 11 เป็น 0; โหมด Cross และการแปลง threshold เดิมคงเดิม
- เก็บ Histogram ของแท่งปิดก่อนหน้าใน core; ไม่ใช้ tick ของแท่งสดและไม่วาด swing ก่อนปิดแท่ง
- คงเลข, HH/HL/LH/LL, markers, เส้นเชื่อม และ outputs เดิมให้ใช้กับทั้งสองโหมด โดยแยกนับต่อ instance
- ต่อ input mode ใหม่ท้ายรายการเพื่อคง positional arguments เดิมของ iCustom; ไม่เปลี่ยนหมายเลข buffers
- เพิ่มชื่อโหมด Cross/Histogram ในชื่อ indicator และ popup
- เพิ่ม fixtures ตามตัวอย่างผู้ใช้, ค่าเท่ากัน/ศูนย์, oracle ของสีและ extreme, เปรียบเทียบ incremental/rebuild ทั้งสองโหมด และตรวจว่าค่า cross filter ไม่แทรกแซงโหมดสี
- ชุดทดสอบเวอร์ชันนี้ผ่าน **42,137 checks**; ชุด regression เดิม 24,003 checks ผ่านก่อนเพิ่ม tests ใหม่

## 1.00 — 2026-09-12

เป็น indicator ใหม่ชื่อ `MACDSwingCount` ในโปรเจค MT5 Trading Tools เริ่มเลขเวอร์ชันของตัวเองที่ 1.00 เปรียบเทียบกับแนวคิดและพฤติกรรมของ `MACD_CROSS_SwingCount` 3.1 ที่ผู้ใช้นำมาให้ศึกษา ไม่ได้แทนที่หรือแก้ไฟล์ต้นฉบับบน Desktop

### แก้ไขความถูกต้อง

| เรื่อง | ต้นฉบับ 3.1 | เวอร์ชันใหม่ |
|---|---|---|
| Cross ที่ยังไม่ถึงระยะ | ต้อง cross และถึง threshold ในแท่งเดียว; แท่งถัดไปแม้ระยะถึงก็อาจพลาด | คงสถานะขาเดิมจน Histogram ถึงเกณฑ์ฝั่งตรงข้าม จึงรับการแยกออกช้า ๆ ได้ |
| Seed EMA | ใช้ค่าเฉลี่ยหลายแท่งใส่ย้อนถึงแท่งต้นประวัติ | เริ่มจาก source แรกแล้วคำนวณตามลำดับเวลา ไม่อ่านข้อมูลข้างหน้า |
| Period ยาวกว่าประวัติ | ค่า seed อาจรวมแท่งสดและเปลี่ยน MACD ของแท่งเก่า | ไม่อ่านแท่งสดเลย; warmup อัตโนมัติรอข้อมูลตาม periods |
| จุดเริ่ม swing | Seed extreme ที่ index 2 แต่เริ่ม loop ที่ 50 | Seed ขาแรกที่แท่งเดียวกับจุดเริ่มตรวจหลัง warmup แล้วประมวลผลต่อทุกแท่ง |
| ประวัติ 50 → 51 แท่ง | state อาจต่างจากการ reload 51 แท่ง | ไม่ใช้จำนวน 50 คงที่ ผล incremental/full rebuild ผ่านการเปรียบเทียบ |
| การ rebuild | พึ่งเงื่อนไขเริ่มต้นเป็นหลัก | ตรวจ prev_calculated, ขนาดประวัติ, เวลาแท่งแรก และเวลาแท่งปิดล่าสุดที่ประมวลผล |
| Inputs | ไม่มี validation ครบถ้วน | ตรวจ lengths, warmup, threshold, ขอบเขตการแสดงผล และตัวเลขไม่ถูกต้อง |
| ข้อมูลผิดปกติ | ไม่มีเกณฑ์ชัดเจน | OHLC ผิดรูป/NaN/overflow รีเซ็ต core และเริ่ม warmup ใหม่; ไม่สร้าง event บนข้อมูลผิด |

### เพิ่มฟีเจอร์

- Threshold เลือกเป็นราคา, points หรือสัดส่วน ATR ได้
- Warmup อัตโนมัติหรือกำหนดจำนวนแท่งเอง
- เลขย้อนหลังพร้อม HH/HL/LH/LL และ EH/EL; เลือกแสดงเลขอย่างเดียวหรือโครงสร้างอย่างเดียวได้
- Marker บนแท่งยืนยัน แยกจากเลขที่ตำแหน่งยอด/ก้น
- เส้นเชื่อมเฉพาะ swing ที่ยืนยันแล้ว เปิด–ปิดได้
- Tooltip ระบุราคา เวลาแท่งยอด/ก้น และเวลาแท่งยืนยัน
- Event buffers บนแท่งยืนยันสำหรับ EA: ชนิด ราคา เวลา pivot และ classification
- MACD/Signal/Histogram/threshold buffers สำหรับตรวจสอบตัวเลขกับ indicator อื่น
- Popup แบบเปิดเองใน Inputs เฉพาะ event ใหม่ ไม่มี alert ย้อนหลังตอน attach/rebuild
- Prefix object เฉพาะ instance พร้อม owner object; ถอดตัวหนึ่งไม่สั่งลบ label ของอีกตัว

### ปรับประสิทธิภาพและโครงสร้าง

- แยก `SwingCore.mqh` ให้ทดสอบสูตรและ swing engine โดยไม่ต้องใช้ MT5
- คำนวณครั้งแรกตามจำนวนแท่ง จากนั้นคำนวณเฉพาะแท่งที่เพิ่งปิด; tick ซ้ำในแท่งเดียวไม่คำนวณประวัติ MACD ใหม่
- วาดเลขและเส้นใหม่เฉพาะเมื่อมี swing เพิ่มหรือ rebuild ประวัติ
- เลิกสร้าง iMACD handle ที่ไม่ได้อ่านค่า
- รวมใน `scripts/products.json`, test runner, compile และ package ของโปรเจค
- เพิ่มคู่มือใหม่, เอกสารเปรียบเทียบ, ผลทดสอบ และ ZIP ที่ติดตั้งแยกตัวได้

### พฤติกรรมที่คงไว้

- MACD main เป็น Fast EMA − Slow EMA; Signal เป็น EMA ของ MACD
- ใช้ Close ของ symbol/timeframe บนกราฟ
- ใช้ High/Low ของ wick เป็น extreme เลือกแท่งล่าสุดเมื่อราคาเท่ากัน
- แท่งยืนยันอยู่ในขาเก่าและเริ่มขาใหม่ด้วย
- เลข 1 คือ swing ล่าสุด รวม High และ Low; จำนวนเลขย้อนหลังเริ่มที่ 10
- จุด swing วางย้อนหลังเมื่อยืนยันจากแท่งที่ปิดแล้ว ไม่ใช่จุดเข้าเทรดอัตโนมัติ

### สิ่งที่ต้องทราบก่อนย้ายจากต้นฉบับ

- **ไม่รับประกันตำแหน่ง swing ตรงต้นฉบับ 1:1** โดยเฉพาะช่วงต้นประวัติ, periods ยาว และ threshold > 0 เพราะแก้ logic โดยตั้งใจ
- `SignalSMA` เปลี่ยนเป็น `InpSignalEMA` ให้ชื่อตรงกับสูตร
- ค่าไม่มีสัญญาณเปลี่ยนจาก `0.0` เป็น `EMPTY_VALUE` รองรับราคาศูนย์/ติดลบและไม่ตีความศูนย์เป็นจุดว่าง
- Buffer 0/1 ยังเป็น High/Low ย้อนหลัง แต่ EA ควรใช้ buffers 2–5 เพื่อตรวจ event เมื่อยืนยันจริง
- จุดตัวเลขเลื่อนลำดับเมื่อมี swing ใหม่ เป็นพฤติกรรมของ numbering ไม่ใช่การแก้ราคา pivot เดิม
- โหมด ATR เปลี่ยน threshold ตาม ATR ของแต่ละแท่ง; seed ATR เริ่มจาก TR แรก ไม่อ้างว่าเท่ากับ iATR ในช่วงต้น
- สูตร EMA สอดคล้องกับแนวทางของ TVStyleMACD ในโปรเจค แต่ไม่ได้เปลี่ยนหรือสร้าง dependency ไปยังไฟล์เดิม การรวมเป็น library กลางยังไม่ได้ทำ
- ไม่เพิ่มระบบเทรด/Telegram และยังไม่ได้เชื่อม PAReversal หรือรับรอง parity กับ `MACD_CROSS_SwingAlert`
