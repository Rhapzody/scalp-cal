# MACD Zone Pullback 1.10

Indicator MT5 สำหรับเงื่อนไข **M5 เบรก swing ด้วยแรงส่ง → กลับเข้า Demand/Supply zone → M1 ปิดทะลุ LH/HL**

ทั้ง M5 และ M1 ใช้ **MACD Histogram เปลี่ยนสี** จาก core เดียวกับ MACD Swing Count ในโปรเจค ไม่ใช้โหมด MACD/Signal cross และใช้ราคา swing ที่ปลายไส้เทียน มี source, tests และ EX5 ของตัวเอง ไม่ต้องติด indicator ตัวอื่นก่อน

## ลำดับการทำงาน

### 1. หา swing และการเบรกบน M5

- ใช้ MACD EMA/EMA จาก Close, ค่าเริ่มต้น 12/26/9 และกติกา Histogram color ของ MACD Swing Count
- เก็บ Swing High/Low ที่ยืนยันแล้วเท่านั้น
- **Buy setup:** M5 ปิดสูงกว่า Swing High ล่าสุดที่ยังไม่เคยถูกปิดทะลุ
- **Sell setup:** M5 ปิดต่ำกว่า Swing Low ล่าสุดที่ยังไม่เคยถูกปิดทะลุ
- ไส้แทงผ่านหรือปิดเท่าระดับไม่นับว่าเบรก
- ทดสอบคุณภาพเฉพาะการปิดทะลุครั้งแรก ถ้าไม่ผ่านจะไม่ย้อนใช้ swing เดิมสร้าง setup จากการเบรกซ้ำ
- จุดเริ่มขาเบรกคือ opposite swing ล่าสุดที่ยืนยันแล้ว เช่น Swing Low ก่อนเบรก High โดย origin ต้องไม่เก่ากว่า swing ที่ถูกเบรก และต้องอยู่ก่อนแท่งเบรก
- opposite swing ที่เพิ่งยืนยันพร้อมแท่งเบรกใช้ได้ เพราะทราบทั้งสองอย่างเมื่อแท่งนั้นปิด

### 2. ตรวจแรงส่งของขาเบรก

นับตั้งแต่แท่ง origin swing ถึงแท่งเบรก โดยใช้ ATR M5 ของ **แท่งก่อนเบรก** (True Range + Wilder smoothing จาก SwingCore) ไม่ใช้แท่งเบรกเพิ่มฐาน ATR ของตัวเอง

ทั้งสองระดับคุณภาพต้องผ่าน:

```text
net = ทิศทาง × (Close แท่งเบรก − Close แท่ง origin)
net ≥ InpMinLegATR × ATR
จำนวนแท่งในขา ≤ InpMaxLegBars
```

ค่าเริ่มต้น `InpMinLegATR=1.0`, `InpMaxLegBars=30` ปฏิเสธขาที่มีช่องว่างเวลา M5 เพื่อไม่ให้ session gap/ข้อมูลขาดถูกใช้แทนแรงส่งต่อเนื่อง

**Quality 2 — FVG:** พบ FVG ทิศเดียวกับขาเบรกภายในขานั้น ขนาดไม่น้อยกว่า `InpMinFVGATR × ATR` (ค่าเริ่มต้น 0.10) ใช้ FVG ระหว่างไส้แท่ง 1/3 และแท่ง 2 ต้องครอบคลุมช่องว่าง ไม่ต้องบังคับสีแท่งกลาง FVG เป็นหลักฐานว่าเคยเกิด imbalance ในขานั้น ไม่ได้บังคับว่าช่องว่างยังไม่ถูกเติมในตอนเบรก

**Quality 1 — Displacement:** เมื่อไม่มี FVG ที่ผ่านเกณฑ์ และเลือก `RP_FVG_OR_DISPLACEMENT` ต้องผ่านครบ:

- `efficiency = net / ผลรวม |Close[i] − Close[i−1]|` ไม่น้อยกว่า 0.65 โดยค่าเริ่มต้น
- แท่งเบรกมี body ไปทิศเดียวกับการเบรก และ body/range ไม่น้อยกว่า 0.50
- ราคาปิดอยู่ในสัดส่วน `InpMaxCloseTailRatio` ด้านปลายทางของแท่งเบรก (ค่าเริ่มต้น 25%) เช่น Buy ปิดในหนึ่งในสี่บนของช่วง High–Low

เลือก `RP_FVG_ONLY` เพื่อปิดการรับ Quality 1 ได้ ตัวกรองเหล่านี้เป็น **กติกาที่กำหนดเพื่อให้ทดสอบได้** ค่าเริ่มต้นยังไม่ได้ optimize หรือพิสูจน์ผลเทรด ไม่ใช่การวัด order flow จากสมุดคำสั่ง

### 3. สร้างโซนได้สองแบบ

`InpZoneMode` เลือก `RP_BOTH` (ค่าเริ่มต้น), `RP_SWING_ZONE` หรือ `RP_ORIGIN_ZONE`

| แบบ | แท่งที่ใช้สร้างโซน | ขอบเขต |
|---|---|---|
| Swing flip | แท่งที่สร้าง swing M5 ซึ่งถูกเบรก | Low–High เต็มแท่ง รวมไส้ |
| Impulse origin | แท่งสวนทางหรือ doji ล่าสุด ตั้งแต่ origin swing ถึงก่อนแท่งเบรก; ถ้าไม่มีใช้แท่ง origin swing | Low–High เต็มแท่ง รวมไส้ |

**SR เป็นราคาไส้ของ swing ที่ถูกเบรก ส่วนพื้นที่เข้าใกล้ใช้ขอบเขตโซน** จึงอาจอยู่คนละราคากันในโหมด origin ไม่มีระยะ points เพิ่มรอบเส้น

โซนนี้ใช้ฐานหนึ่งแท่งตามกติกาข้างต้น ยังไม่ได้รวม base หลายแท่งแบบ Rally–Base–Rally หรือ Drop–Base–Drop โดยอัตโนมัติ

Buy ต้องปิดเบรกเหนือขอบบนโซน และ Sell ต้องปิดเบรกใต้ขอบล่าง เพื่อยืนยันว่าออกจากโซนไปแล้ว หากไม่พ้นขอบจะไม่สร้างโซนนั้น สองโซนที่ขอบบน/ล่างตรงกันพอดีจะแสดงเพียงโซนเดียว

โซนเริ่มวาดที่ **เวลาปิดแท่งเบรก M5** ไม่วาดย้อนหลังเหมือนรู้โซนตั้งแต่แท่งต้นทาง Tooltip บอกทั้งเวลาแท่งต้นทางและเวลาที่ทราบ setup

### 4. รอราคาเข้าโซน แล้วตรวจ M1

ค่าเริ่มต้นใช้ช่วง High–Low ของ **แท่ง M1 ที่ปิดแล้ว** ตัดกับโซน M5 เพื่อตรวจการกลับเข้าพื้นที่ แตะขอบพอดีนับด้วย จึงตรวจการย่อภายในแท่ง M5 ได้โดยไม่ต้องรอ M5 ปิด

หลังเข้าโซนแล้ว:

- **Buy:** รอแท่ง M1 ถัดไปหรือหลังจากนั้น ปิดสูงกว่า **Lower High ล่าสุดที่ยืนยันแล้ว**
- **Sell:** รอแท่ง M1 ถัดไปหรือหลังจากนั้น ปิดต่ำกว่า **Higher Low ล่าสุดที่ยืนยันแล้ว**
- ใช้ Histogram color และค่า MACD ชุดเดียวกับ M5 ทั้งสอง timeframe
- ไม่บังคับให้สร้าง Higher Low/Lower High เพิ่มหลังการเบรก ไม่เพิ่มเงื่อนไข LL/HH อีกชุดนอกเหนือจาก LH/HL ที่ระบุ
- ไส้แทงผ่านหรือราคาปิดเท่าระดับไม่ให้สัญญาณ
- LH/HL ที่ถูกปิดทะลุไปแล้วก่อนเข้าโซนใช้ซ้ำไม่ได้ ต้องมี swing ใหม่ที่เข้าเงื่อนไข
- ใช้ระดับที่ทราบก่อนแท่งสัญญาณเริ่มเท่านั้น ไม่ใช้ swing ที่เพิ่งยืนยันเมื่อแท่งสัญญาณเดียวกันปิด
- ถ้าแท่งเดียวทั้งแตะโซนและเบรก LH/HL **ไม่นับสัญญาณ** เพราะ OHLC ไม่บอกลำดับเหตุการณ์ระหว่างแท่ง และไม่ใช้การเบรกครั้งนั้นซ้ำในแท่งถัดไป
- แท่ง M1 ภายในแท่งเบรก M5 ไม่สามารถย้อนกลับมาเป็น retest ของโซนที่เพิ่งเกิดเมื่อ M5 ปิด

หนึ่ง breakout ให้สัญญาณได้หนึ่งครั้งร่วมกันระหว่างสองประเภทโซน หลังส่งสัญญาณจะหยุดรอทั้งสองโซนของ breakout นั้น หากมีหลาย setup ให้สัญญาณทิศเดียวกันพร้อมกัน จะแสดงลูกศรเดียวพร้อมข้อมูลของ setup ที่ถูกเลือก

### การยกเลิกและหมดอายุ

- **ค่าเริ่มต้น M1 ปิดเลยขอบไกลของโซน:** Buy ปิดต่ำกว่า Low โซน / Sell ปิดสูงกว่า High โซน → ยกเลิกโซนนั้นทันที ไส้ทะลุแต่ปิดกลับเข้ามายังไม่ยกเลิก
- **รอสัญญาณเกิน `InpConfirmationBars`:** เริ่มนับหลังแตะโซนครั้งแรก; ค่าเริ่มต้น 30 แท่ง M1 แตะซ้ำไม่ต่ออายุ
- **โซนอายุครบ `InpZoneLifeBars`:** ค่าเริ่มต้น 144 แท่ง M5
- อายุทั้งสองแบบนับแท่งข้อมูลที่มี ไม่ใช่เวลานาฬิกา จึงไม่เพิ่มจำนวนแท่งระหว่างตลาดปิด
- แต่ละโซนถูกยกเลิกแยกกัน เช่น swing flip เสียแล้ว origin ที่อยู่ลึกกว่ายังรอได้ ตราบที่ยังไม่เกิด entry ของ breakout เดียวกัน

## การแสดงผลและติดตั้ง

1. แตก `MACDZonePullback-1.10.zip`
2. คัดลอก `MQL5/Indicators/MACDZonePullback` ไปยัง `MQL5/Indicators/` ใน MT5 Data Folder
3. Refresh Navigator แล้วลาก **MACDZonePullback** ลงกราฟ **M1 หรือ M5** ของ symbol ที่ต้องการ
4. ใช้ M5 ดูพื้นที่ แล้วเปลี่ยนกราฟเป็น M1 ดูแท่งยืนยัน ทั้งสองกราฟคำนวณ M5/M1 ให้อัตโนมัติ ไม่ต้องเปิดอีกกราฟเพื่อป้อนข้อมูล

- โซน Demand สีเขียว / Supply สีแดง
- กรอบทึบ = Swing flip, กรอบเส้นประ = Impulse origin; แสดงกรอบเปล่าเป็นค่าเริ่มต้น
- เส้นจุดแนวนอน = ราคาไส้ swing M5 ที่ถูกเบรก
- กรอบหนาขึ้น = แตะโซนแล้วและรอ M1
- ลูกศร Buy/Sell อยู่บนเวลาแท่ง M1 ที่ให้สัญญาณ ณ ราคาปิด ต้องรอแท่งนั้นปิดก่อนจึงทราบสัญญาณ
- Tooltip บอกประเภทโซน, FVG/Displacement, เวลา confirm, ราคาปิดและ LH/HL ที่ถูกเบรก
- แสดงเฉพาะโซนที่ยัง active; โซนที่ใช้แล้ว ยกเลิก หรือหมดอายุจะหายไป ลูกศรย้อนหลังยังแสดงตามจำนวนที่ตั้ง
- เปลี่ยน timeframe ด้วยตนเองตามต้องการ Indicator ไม่สลับหน้ากราฟให้อัตโนมัติ และไม่มีการส่งคำสั่งซื้อขาย

Popup เป็นตัวเลือก ปิดไว้เป็นค่าเริ่มต้น เมื่อเปิดจะแจ้งเฉพาะสัญญาณจากแท่ง M1 ที่เพิ่งปิด ไม่แจ้งประวัติทั้งหมดตอนแนบ/โหลดใหม่ และไม่ไล่แจ้งสัญญาณเก่าทุกแท่งหลังขาดการเชื่อมต่อ

### การปรับค่าร่วมกันระหว่าง Indicator กับ EA

ค่ากลุ่ม MACD, ประวัติ, โซน, แรงส่ง, ระยะรอยืนยัน และ Signal tuning ต้องตรงกันเมื่อใช้เทียบสัญญาณ รวมทั้งใช้ symbol และประวัติช่วงเดียวกัน ค่าเริ่มต้นของรุ่น 1.10 คงกติกาสัญญาณของ 1.00 ไว้

- Buffer ใช้ **points ของ symbol**: ระยะราคา = จำนวน points × `_Point` เช่น `_Point=0.01` และ 20 points คือราคา 0.20
- Buy ต้องปิด **สูงกว่า** ราคา swing + buffer; Sell ต้องปิด **ต่ำกว่า** ราคา swing − buffer การปิดเท่าระดับยังไม่ผ่าน ทั้ง M5 และ M1
- ถ้าผ่านราคา swing เดิมแต่ยังไม่ผ่าน buffer จะยังไม่ใช้สิทธิ์เบรกนั้น เงื่อนไขห้ามใช้การเบรกก่อน touch และห้าม touch/เบรกในแท่งเดียวกันนับจากระดับที่รวม buffer แล้ว
- Touch ตรวจจากแท่ง M1 ที่ปิดแล้วเสมอ: โหมดไส้ยอมรับช่วง High–Low ตัดโซน; โหมด Close ต้องปิดอยู่ในโซน รวมกรณีเท่าขอบ
- Invalidation ตรวจขอบไกลก่อน touch/entry: โหมด Wick จะยกเลิกเมื่อไส้เลยขอบ แม้ปิดกลับเข้ามา; เท่าขอบยังไม่ยกเลิก
- `InpMaxCloseTailRatio` ใช้เฉพาะขาที่ผ่านด้วย displacement ค่าเล็กบังคับ Close ใกล้ปลายแท่งมากขึ้น; 0 ต้องปิดตรงปลาย และ 1 ไม่จำกัดตำแหน่ง Close แต่ยังตรวจ body/efficiency ไม่เปลี่ยนกติกา FVG

ค่าความเสี่ยงและ SL/TP buffer อยู่ใน EA ส่วน Indicator แสดงโซนและสัญญาณ ไม่คำนวณ lot หรือส่ง order เปลี่ยน Inputs แล้วระบบคำนวณประวัติใหม่ จึงควรบันทึกชุดค่าที่ใช้ทุกครั้งที่เปรียบเทียบผล

## Buffers / iCustom

Inputs ใหม่ต่อท้าย Inputs เดิมเพื่อคงลำดับเรียก `iCustom` เมื่อไม่ส่งค่าใหม่จะใช้ค่าเริ่มต้น Tooltip แยกราคา swing เดิมกับ Break level ที่รวม buffer

Buffers เป็น `DRAW_NONE` และใช้ `EMPTY_VALUE` เมื่อไม่มีสัญญาณ:

| Index | ค่า |
|---|---|
| 0 | ราคาปิด M1 ของ Buy |
| 1 | ราคาปิด M1 ของ Sell |
| 2 | เวลาเปิดแท่ง M1 ที่ส่งสัญญาณ (Unix); ทราบผลที่เวลา +60 วินาที |
| 3 | ราคา LH/HL เดิมที่ถูกเบรก ไม่รวม M1 break buffer |
| 4 / 5 | ขอบล่าง / ขอบบนโซน |
| 6 | ราคา SR จากไส้ swing M5 ที่ถูกเบรก |
| 7 | Quality: 2 = FVG, 1 = Displacement |

บน M1 จะไม่มีสัญญาณจากแท่ง M1 ที่ยังไม่ปิด บน M5 แท่ง M5 ปัจจุบันอาจมี buffer ได้เมื่อ M1 ภายในปิดให้สัญญาณแล้ว ถ้า M5 หนึ่งแท่งมีหลายสัญญาณ buffers จะเก็บเฉพาะรายการล่าสุด ส่วน object ลูกศรยังแสดงรายการย้อนหลังตาม VisibleSignals การซ่อนภาพไม่ปิดการคำนวณ buffers

## ขอบเขตประวัติและการคำนวณ

คำนวณตามลำดับเวลาจริงจากข้อมูลปิดของสอง timeframe และคำนวณใหม่เมื่อมีแท่ง M1 ใหม่/ประวัติกราฟถูก reset เลือกหน้าต่าง M5 ตาม HistoryM5Bars แล้วโหลด M1 ในช่วงนั้น เมื่อ M1 มีประวัติสั้นกว่าจะเริ่มสร้าง setup ภายในช่วงข้อมูลร่วมกัน เพื่อไม่คาดเดาว่าโซนเก่าถูกแตะ/ยกเลิกไปแล้วหรือยัง

EMA ใช้สูตรเดียวกับ MACD Swing Count แต่เริ่ม seed จากประวัติที่โหลดของแต่ละ timeframe ผลอาจต่างจากอีก instance ที่ใช้จุดเริ่มประวัติไม่เหมือนกัน การเลื่อนหน้าต่าง, เติมประวัติ, แก้ราคา หรือเปลี่ยน Inputs อาจเปลี่ยนผลที่คำนวณย้อนหลัง จึงไม่อ้างว่าไม่มีการเปลี่ยนผลย้อนหลังทุกกรณี

เก็บโซนพร้อมกันได้สูงสุด 256 ช่องภายใน engine โดยนำช่องของโซนที่จบแล้วกลับมาใช้ ถ้าเต็มด้วย active ทั้งหมดจะหมุนแทนที่หนึ่งโซน ขีดจำกัดนี้แยกจากจำนวนโซนที่วาดและหน้าต่างประวัติ

API อ้างอิง: [CopyRates](https://www.mql5.com/en/docs/series/copyrates) สำหรับข้อมูล M5/M1 และ [OnCalculate](https://www.mql5.com/en/docs/event_handlers/oncalculate) สำหรับการเปลี่ยนประวัติและการคำนวณซ้ำ
