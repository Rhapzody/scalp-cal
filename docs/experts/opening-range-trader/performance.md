# Opening Range Trader — performance log

ยังไม่มี market backtest/forward test ในชุดส่งมอบ จึงไม่มี win rate ที่ยืนยันได้

| รายการ | ค่า |
|---|---|
| Symbol / broker / server time | ยังไม่ระบุ |
| ช่วงทดสอบและ model | ยังไม่ระบุ |
| จำนวน trade | ยังไม่ระบุ |
| Win rate | ยังไม่ระบุ |
| Average win/loss สุทธิ | ยังไม่ระบุ |
| Realized RR / expectancy | ยังไม่ระบุ |
| Profit factor / max drawdown | ยังไม่ระบุ |
| Spread / commission / slippage | ยังไม่ระบุ |
| Out-of-sample / forward demo | ยังไม่ระบุ |

อย่าใช้ค่า target 2R แทน realized RR เพราะการเข้า, spread และการปิดจริงอาจเปลี่ยนผลลัพธ์
